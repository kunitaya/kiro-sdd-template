# kiro-sdd-template

Kiroを用いた仕様駆動開発（Spec-Driven Development / SDD）のための、汎用的な開発環境テンプレートです。

AIエージェント向け指示、Steering、Specテンプレート、実装・レビュー手順を集約し、プロジェクトごとに調整して使える開発フローを整備します。

> 現在は整備中です。追加済みのファイルは、このREADMEと `LICENSE` です。以下のテンプレートや手順は収録予定であり、導入手順は内容が揃ってから追記します。

## 目的

- 要件・設計・タスクを整理し、仕様に基づいて実装と検証を進める。
- AIエージェントが参照する共通指示と、作業ごとの手順を明確にする。
- Specレビューと実装レビューの観点・記録方法を揃える。
- 特定の業務や技術構成に依存しないひな形を、複数のプロジェクトで再利用する。

## 想定する利用者・用途

- Kiroで仕様駆動開発を始めたい個人開発者やチーム。
- AIエージェント向けの指示やレビュー手順を、GitHubで管理したい方。
- プロジェクトごとに繰り返している開発環境の準備を共通化したい方。

## 収録予定

以下は今後整備する内容です。具体的なファイル構成は、追加時にこのREADMEへ反映します。

| 内容 | 用途 |
|---|---|
| `AGENTS.md` | AIエージェント向けの共通指示、作業範囲、基本ルール |
| `.kiro/steering/` | Kiroで参照する開発方針と作業手順 |
| Specテンプレート | 要件・設計・タスクを記述するひな形 |
| 実装用プロンプト・手順 | Specに基づくタスク実行、検証、結果記録 |
| レビュー用テンプレート・手順 | Specレビュー、コードレビュー、要件適合確認 |
| 導入・カスタマイズ手順 | 新規プロジェクトへの適用と、プロジェクト固有の設定 |

## 利用にあたって

本リポジトリは、個人が提供する非公式のテンプレートです。Kiroの開発元による公式提供・承認を示すものではありません。

利用する際は、プロジェクトの要件、技術構成、開発体制に合わせて内容を調整してください。対応環境や動作確認結果は、テンプレートの整備に合わせて記載します。

改善案や不具合の報告は、[Issues](https://github.com/kunitaya/kiro-sdd-template/issues)で受け付けます。
